# Plataforma Educativa de Razonamiento Lógico-Matemático

Aplicación móvil orientada al aprendizaje interactivo de lógica matemática mediante mecánicas de gamificación (lecciones progresivas, ejercicios adaptativos, puntos de experiencia, niveles e insignias).

## 🌿 Flujo de Trabajo en Git

Para mantener la estabilidad del proyecto, el equipo trabaja bajo el siguiente esquema de ramas:

* `main`: Rama de producción. Solo contiene código estable y verificado.
* `develop`: Rama principal de integración para el equipo.
* `feature/<nombre-tarea>`: Ramas individuales para el desarrollo de funcionalidades específicas.

### Buenas prácticas de commit:
- `feat:` Nuevas funcionalidades.
- `fix:` Corrección de errores o bugs.
- `docs:` Cambios en la documentación (como este README).
- `style:` Cambios visuales o formateo sin afectar la lógica del código.
